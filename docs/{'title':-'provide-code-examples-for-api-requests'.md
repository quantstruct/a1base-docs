
# API Reference with Code Examples

This document provides code examples for various API endpoints to help developers integrate with our platform quickly and efficiently.  It complements the existing quickstart guide by providing examples in multiple languages for each endpoint.

## General Information

*   **Base URL:**  `[Your API Base URL]` (Replace with your actual base URL)
*   **Authentication:** All endpoints require authentication via `x-api-key` and `x-api-secret` headers.  Obtain these credentials from your account dashboard.
*   **Error Handling:**  The API returns standard HTTP status codes.  4xx errors indicate client-side issues (e.g., invalid parameters), while 5xx errors indicate server-side issues.  Error responses are typically in JSON format and include a `detail` field with more information.

## Messages API

### Send Individual Message (`/v1/messages/individual/{accountId}/send`)

This endpoint allows you to send a message to an individual recipient.

**Method:** `POST`

**Path Parameters:**

*   `accountId` (string, required): Your account ID.

**Headers:**

*   `x-api-key` (string, required): Your API key.
*   `x-api-secret` (string, required): Your API secret.

**Request Body (JSON):**

```json
{
  "content": "Hello, this is a test message.",
  "attachment_uri": "https://example.com/image.jpg",
  "from": "61421868490",
  "to": "61433174782",
  "service": "whatsapp"
}
```

#### Code Examples

**cURL:**

```bash
curl -X POST '[Your API Base URL]/v1/messages/individual/{accountId}/send' \
-H 'Content-Type: application/json' \
-H 'x-api-key: YOUR_API_KEY' \
-H 'x-api-secret: YOUR_API_SECRET' \
-d '{
  "content": "Hello, this is a test message.",
  "attachment_uri": "https://example.com/image.jpg",
  "from": "61421868490",
  "to": "61433174782",
  "service": "whatsapp"
}'
```

**Node.js:**

```javascript
const https = require('https');

const options = {
  hostname: '[Your API Base URL]',
  path: '/v1/messages/individual/{accountId}/send',
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': 'YOUR_API_KEY',
    'x-api-secret': 'YOUR_API_SECRET'
  }
};

const data = JSON.stringify({
  "content": "Hello, this is a test message.",
  "attachment_uri": "https://example.com/image.jpg",
  "from": "61421868490",
  "to": "61433174782",
  "service": "whatsapp"
});

const req = https.request(options, (res) => {
  console.log(`statusCode: ${res.statusCode}`);

  res.on('data', (d) => {
    process.stdout.write(d);
  });
});

req.on('error', (error) => {
  console.error(error);
});

req.write(data);
req.end();
```

**Python:**

```python
import requests
import json

url = "[Your API Base URL]/v1/messages/individual/{accountId}/send"

payload = json.dumps({
  "content": "Hello, this is a test message.",
  "attachment_uri": "https://example.com/image.jpg",
  "from": "61421868490",
  "to": "61433174782",
  "service": "whatsapp"
})
headers = {
  'Content-Type': 'application/json',
  'x-api-key': 'YOUR_API_KEY',
  'x-api-secret': 'YOUR_API_SECRET'
}

response = requests.request("POST", url, headers=headers, data=payload)

print(response.text)
```

### Get Message Details (`/v1/messages/individual/{accountId}/get-details/{messageId}`)

This endpoint retrieves details for a specific message.

**Method:** `GET`

**Path Parameters:**

*   `accountId` (string, required): Your account ID.
*   `messageId` (string, required): The ID of the message to retrieve.

**Headers:**

*   `x-api-key` (string, required): Your API key.
*   `x-api-secret` (string, required): Your API secret.

**Response (JSON):**

```json
{
  "messageId": "some_unique_id",
  "to": "61433174782",
  "from": "61421868490",
  "body": "Hello, this is a test message.",
  "status": "sent",
  "timestamp": "2024-10-27T10:00:00Z"
}
```

#### Code Examples

**cURL:**

```bash
curl -X GET '[Your API Base URL]/v1/messages/individual/{accountId}/get-details/{messageId}' \
-H 'x-api-key: YOUR_API_KEY' \
-H 'x-api-secret: YOUR_API_SECRET'
```

**Node.js:**

```javascript
const https = require('https');

const options = {
  hostname: '[Your API Base URL]',
  path: '/v1/messages/individual/{accountId}/get-details/{messageId}',
  method: 'GET',
  headers: {
    'x-api-key': 'YOUR_API_KEY',
    'x-api-secret': 'YOUR_API_SECRET'
  }
};

const req = https.request(options, (res) => {
  console.log(`statusCode: ${res.statusCode}`);

  res.on('data', (d) => {
    process.stdout.write(d);
  });
});

req.on('error', (error) => {
  console.error(error);
});

req.end();
```

**Python:**

```python
import requests

url = "[Your API Base URL]/v1/messages/individual/{accountId}/get-details/{messageId}"

headers = {
  'x-api-key': 'YOUR_API_KEY',
  'x-api-secret': 'YOUR_API_SECRET'
}

response = requests.request("GET", url, headers=headers)

print(response.text)
```
