
# Sending Group Messages: The `from` Parameter

This document updates the documentation for sending group messages to include the `from` parameter. This parameter is essential for specifying the agent's phone number when sending messages.

**Target Audience:** Developers

**Related Endpoint:** `POST /messages/group/{accountId}/send`

## API Reference

This endpoint allows you to send messages to a group.
